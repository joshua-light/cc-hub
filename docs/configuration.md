# Configuration reference

hal reads `~/.hal/config.toml` once, at startup. The file is optional.
Every key has a default, so list only what you change.

Unknown keys are rejected. A read or parse error, including one unknown key,
makes hal ignore the whole file and use the defaults. The only signal is a
`config: parse error … — using defaults` warning in the log.

The resource broker has its own file, `~/.hal/resources.toml`; see
[resource-management.md](resource-management.md).

## `[spawn]`

| Key | Default | Meaning |
|---|---|---|
| `command` | `"hal-new"` | Command for the built-in `claude` agent. Runs through your interactive shell, so aliases and functions work. |
| `ask_name` | `true` | Ask for a name when you start a session or terminal from the TUI; Enter on the name opens it. Off, the new session opens at once. A respawn keeps its old name and never asks. |

## `[agents.<id>]`

One table per coding agent. The built-in agent `claude` always exists (kind
`claude`, `[spawn].command`); an `[agents.claude]` table replaces it. Every
account in `resources.toml` also becomes an agent under its own name, unless
a table here already uses that name.

| Key | Default | Meaning |
|---|---|---|
| `kind` | `"claude"` | Backend: `claude`, `pi` or `codex`. |
| `command` | `"hal-new"` | Shell command that starts the agent. hal appends model, resume and prompt arguments, so keep `--model`/`-m`/`resume` out of it. |
| `use_bridge` | `false` | Pi only: load hal's heartbeat extension, so the hub sees the session's live state. |
| `models` | `[]` | Model-picker entries (`N`). Each is an id string or `{ label, id }`. Empty on a `claude` agent means the three built-in Claude models; on others, the command's own default. |
| `hotkey` | none | One character that spawns this agent in the selected session's folder on the Sessions tab. Shadows the built-in key it collides with. Malformed or duplicate hotkeys are dropped with a log warning. |
| `account` | none | A `resources.toml` account to run under. Spawning fails when the account does not exist or has another provider. |
| `effort` | none | Reasoning effort: `--effort` for Claude, `-c model_reasoning_effort=` for Codex, ignored for Pi. |

```toml
[agents.codex]
kind = "codex"
command = "codex --yolo"
models = [{ label = "GPT 5.6 Sol", id = "gpt-5.6-sol" }]
hotkey = "C"
```

## `[projects]`

| Key | Default | Meaning |
|---|---|---|
| `default_session_agent` | `"claude"` | Agent for new sessions and `hal open`. In the TUI, `A` on the Sessions tab overrides it until restart. |

## `[tasks]`

| Key | Default | Meaning |
|---|---|---|
| `kinds` | `[]` | Words a card may carry as its kind (`T`, `board add --kind`, `&kind=`), in picker order. hal stores the word and passes it on; it never interprets it. |
| `handover_kinds` | `[]` | Kinds worked by two sessions in sequence. A `role=verification` link for any other kind is refused. Empty lets every kind hand over. |

## `[title]`

Background session titles, generated by `[spawn].command --model <model> -p`.

| Key | Default | Meaning |
|---|---|---|
| `enabled` | `true` | Generate titles. Off, cards show the first user message. |
| `model` | `"haiku"` | Model for the title call. |
| `max_length` | `40` | Maximum title length, in characters. |
| `run_timeout_secs` | `45` | Kill a title call after this long. |
| `resolve_timeout_secs` | `10` | Time limit for resolving the spawn command through the shell, paid once per process. |
| `concurrency` | `2` | Maximum title calls at once. |
| `prompt` | see below | Text placed before the session's first user message. |

The default prompt:

```text
Output a 2 or 3 word title summarizing this coding-agent user request. Output only the title — no quotes, no punctuation, no prefix like "Title:". Just the words.

Request:
```

## `[inactive]`

Sessions with no live process.

| Key | Default | Meaning |
|---|---|---|
| `window_secs` | `259200` (3 days) | Show a dead session while its transcript is younger than this. |
| `max_per_project` | `5` | Most inactive sessions shown per folder, newest first. |
| `orphan_relist_secs` | `30` | Re-list an unchanged transcript directory at most this often. A new file invalidates the cache at once. |

## `[scan]`

| Key | Default | Meaning |
|---|---|---|
| `fs_fallback_interval_secs` | `2` | Rescan timer that catches process deaths and missed file events. |
| `usage_refresh_interval_secs` | `60` | How often the TUI reads the account's usage. |
| `usage_cache_ttl_secs` | `60` | How long a stored usage reading counts as fresh before the endpoint is asked again. |

## `[ui]`

| Key | Default | Meaning |
|---|---|---|
| `status_msg_ttl_secs` | `5` | How long a status-bar message stays. |
| `pending_dispatch_timeout_secs` | `60` | How long a new session has to become idle before its queued prompt is dropped. |
| `cell_height` | `6` | Session card height, in rows. At 5 or less the card merges branch, model and id into one row. |
| `cell_width` | `42` | Minimum session card width; the grid fits `terminal width / cell_width` columns. |
| `show_planning_column` | `false` | Show the Planning column on the Tasks board. Hidden, its cards show under In Progress. |
| `dim_unfocused` | `false` | Dim the side without the keyboard on the list-and-page tabs (Sessions' split layout, Builds, Agents). Off, the page's white frame or the list's brighter cursor row marks where typing goes. |

## `[metrics]`

| Key | Default | Meaning |
|---|---|---|
| `min_growth_turns` | `20` | Assistant turns a session needs before context growth is scored. |
| `growth_threshold` | `6.0` | Flag a session when its peak context jump is at least this many times its median jump. |
| `top_interruptions` | `10` | Rows kept in the interrupted-tools list. |
| `top_growth_findings` | `10` | Rows kept in the context-growth list. |
| `top_peak_context_findings` | `10` | Rows kept in the peak-context list. |

## `[harness]`

Persistent agents (the Agents tab).

| Key | Default | Meaning |
|---|---|---|
| `enabled` | `true` | Run the agent supervisor inside the TUI. |
| `show_tab` | `true` | Show the Agents tab. It also stays hidden until `~/.hal/agents/` exists. |
| `refresh_secs` | `3` | How often the TUI rereads agent state (minimum 1). |

## Retired keys

These keys belonged to the removed Projects layer and Builds tab. hal still
accepts and ignores them, so an old file keeps loading: `[backlog]`,
`[auto_review]`, `[builds]`, `[ui].show_projects_tab` and
`[projects].default_orchestrator_agent`.
